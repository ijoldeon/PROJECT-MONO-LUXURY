
# MONO. - Timeless Luxury

**MONO**는 고급스러운 유럽 명품 부티크 스타일을 컨셉으로 제작한 온라인 쇼핑몰 프로젝트입니다.

## 🖥️ 프로젝트 소개
- 프로젝트명: MONO
- 제작 목적: HTML, CSS, JavaScript 학습 및 실습
- 디자인 컨셉: European Luxury Boutique
- 주요 색상: Black & Gold

## 📌 주요 기능
- 상품 목록 및 카테고리별 검색
- 상품 상세 페이지
- 장바구니 상품 추가 및 삭제
- 상품 수량 변경 및 총 금액 계산
- LocalStorage를 이용한 장바구니 저장
- 주문 및 결제 과정 (실제 결제 기능 없음)
- 반응형 웹 디자인

## 📂 파일 구성
- `1.mono.html` : 메인 쇼핑몰
- `2.product.html` : 상품 상세 페이지
- `3.cart.html` : 장바구니
- `4.checkout.html` : 주문 및 결제 페이지
- `5.complete.html` : 주문 완료 페이지
- `mono.css` : 스타일 디자인
- `mono.js` : JavaScript 기능

## 🛠️ 사용 기술
- HTML5
- CSS3
- JavaScript
- LocalStorage

## ⚠️ 참고 사항
본 프로젝트는 학습 및 포트폴리오 목적으로 제작되었으며, 실제 상품 판매 및 결제는 지원하지 않습니다.
