# MONO. 쇼핑몰 프로젝트

**TIMELESS LUXURY, YOUR OWN MOOD.**

MONO는 HTML, CSS, JavaScript를 활용해 제작한 미니멀 럭셔리 패션 쇼핑몰입니다.

## 사용 기술
- HTML5
- CSS3
- JavaScript
- localStorage

## 주요 기능
- 상품 목록 및 검색
- 카테고리별 상품 분류
- 상품 상세 페이지
- 장바구니 추가 및 삭제
- 상품 수량 및 가격 계산
- 연습용 주문 및 완료 화면

## 파일 구성
- `1.mono.html` : 메인 페이지
- `2.product.html` : 상품 상세
- `3.cart.html` : 장바구니
- `4.checkout.html` : 주문 페이지
- `5.complete.html` : 주문 완료
- `mono.css` : 디자인
- `mono.js` : 기능 구현
- `images/` : 상품 이미지

## 실행 방법
`1.mono.html` 파일을 브라우저에서 실행합니다.

※ 본 프로젝트는 학습용이며 실제 결제 기능은 없습니다.
